This directory contains Zahirovic_etal_2022_GPlates.gproj, which is a GPlates (www.gplates.org; a free open-source/cross-platform plate reconstruction software) project file that will load the plate reconstructions and paleogeography. 

Version History
1.0 - Initial submission. Mantle frame was the default, but a technical issue prevented the optimisation from being applied properly. The published model therefore uses the mantle frame from Zahirovic et al. (2016) ESR. 
1.1 - Optimisation of the mantle propagated using the preferred parameters from Muller et al. (2022). 

To load these datasets in GPlates do the following:

1.  Open GPlates
2.  Pull down the GPlates File menu and select Open Project
3.  Click to select the GPROJ file
4.  Click Open 

Alternatively, drag and drop the GRPOJ file onto the globe.

** IMPORTANT **
MANTLE REFERENCE FRAME - Default, tick CombinedRotations in Layers window
OPTIMISED MANTLE REFERENCE FRAME - tick CombinedRotations_Optimised in Layers window
                   
For more information, read the GPlates manual or tutorials which can be downloaded from www.gplates.org.
