        # paleomag — Paleomagnetic databases (GPMDB 2022 snapshot + Osler + Gilder)

        **Provenance:** Multiple curators

        Paleomagnetic data used by cluster F reference-frame + paleomagnetism tutorials: (1) `gpmdb_2022.csv` — 2022 snapshot of the Global Paleomagnetic Database (Torsvik + Van der Voo curators); (2) `osler_upper_sites_*` — Osler VGP compilation; (3) `gilder2001_asian_seds.csv` — Gilder 2001 Asian sedimentary paleomag; (4) rotation files with GPMDB-frame anchors.
