      # climate_proxies — Cold + warm climate proxy points

      **Provenance:** Rogov et al. 2023 glendonite compilation

      Point-locality compilations of paleoclimate proxies used to validate reference-frame choices. Currently contains the Rogov et al. (2023) glendonite database (cold-water diagenetic ikaite pseudomorphs, ~1000 sites through the Phanerozoic).
