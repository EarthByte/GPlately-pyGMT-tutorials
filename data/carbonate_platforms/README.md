      # carbonate_platforms — Zahirovic 2022 active carbonate platforms

      **Provenance:** Zahirovic et al. (2022)

      Time-dependent GPML feature collection of active carbonate platforms through the Phanerozoic — used to estimate CO2 outgassing from platform subduction and to overlay platform outlines on paleogeographic reconstructions.
