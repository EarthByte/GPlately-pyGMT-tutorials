        # paleotemperatures — Multi-study GMST curves for the Phanerozoic

        **Provenance:** Farnsworth 2019 + Landwehrs 2021 + Li 2023 model ensembles

        Compact CSV compilation of Phanerozoic Global Mean Surface Temperature (GMST) curves from three published paleoclimate model ensembles, used for cross-model GMST comparison in T62.
