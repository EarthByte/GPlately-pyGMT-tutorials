      # pbdb — PBDB (Paleobiology Database) taxon-specific caches

      **Provenance:** Paleobiology Database public API

      Cached PBDB REST-API responses for specific taxon/time-window queries so the tutorial notebooks don't hammer the live API on every run. Currently caches the Brachiopoda 440-520 Ma window used by T50.
