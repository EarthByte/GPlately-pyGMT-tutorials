      # thermochronology_afro_arabia — Afro-Arabia thermochronology compilation (Boone-adjacent)

      **Provenance:** Multi-author compilation for Africa + Arabian Peninsula

      Regional thermochronology compilation (fission-track, U-Th/He) for Africa and the Arabian Peninsula, structured like the Boone ThermoPlates central-Asia set. Includes `afro_arabia_thermal_histories.csv` (flat sample-history file, TempDiff column is the authoritative cooling rate) and a supplementary-material subfolder.
