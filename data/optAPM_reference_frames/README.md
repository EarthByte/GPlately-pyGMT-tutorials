      # optAPM_reference_frames — Zahirovic 2022 optimised absolute plate motion reference frames

      **Provenance:** EarthByte + optAPM outputs

      Optimised absolute-plate-motion (optAPM) rotation files for the Zahirovic 2022 plate model in various flavours: paleomag frame (NNR), Torsvik-hotspot frame, and diagnostics CSVs from the optimisation runs. Used in T31/T32/T33 reference-frame comparison tutorials.

      ## Contents

      ```
      optAPM_reference_frames/  (8.1 MB)
Zahirovic2022_NNR.rot (2.7 MB)
Zahirovic2022_NNR_diagnostics.csv
Zahirovic2022_optimised_max_NR.rot (2.7 MB)
Zahirovic2022_optimised_max_NR_diagnostics.csv
Zahirovic2022_optimised_mean_NR.rot (2.7 MB)
Zahirovic2022_optimised_mean_NR_diagnostics.csv
      ```
