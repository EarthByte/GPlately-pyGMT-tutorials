      # sediment_thickness_bird_mooney — Bird & Mooney 2014 GST-14 global sediment thickness (compressed NetCDF)

      **Provenance:** Bird, D.E. & Mooney, W.D. (2014)

      Global sediment thickness on the ~5-arcminute (~9 km) GST-14 grid of Bird & Mooney. **The original release is a 4.15M-point point-cloud (~460 MB); we ship a compressed NetCDF that resamples the point cloud onto a regular grid (~8.4 MB)** for direct pyGMT/xarray consumption. Used by T75 (Panel B raster) and T77 (wedge+drape decomposition of per-basin thickness profiles).
