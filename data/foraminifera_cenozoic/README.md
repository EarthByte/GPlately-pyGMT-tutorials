# foraminifera_cenozoic — Paleobiology Database query response: Cenozoic planktonic foraminifera

**Provenance:** Paleobiology Database public API

`pbdb_planktonic_forams_0_66Ma.csv.gz` is the response of I04's live query of the Paleobiology Database (https://paleobiodb.org/data1.2/occs/list.json with `base_name=Globigerinoidea,Globorotaliidae`, `min_ma=0`, `max_ma=66`, `show=coords,coll`, `vocab=pbdb`, `limit=all`), saved on 11 November 2026: 73,854 occurrences with accepted names, collection numbers and names, age ranges and present-day coordinates. Most collections are DSDP/ODP/IODP core samples (e.g. `321-U1338A-14H-CC`). I04 queries the API live on every run and refreshes this file; it reads the file only when the API cannot be reached.
