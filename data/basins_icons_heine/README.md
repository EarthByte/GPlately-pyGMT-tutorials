        # basins_icons_heine — Heine ICONS Atlas — 870 global sedimentary basins

        **Provenance:** Heine (2007) PhD, EarthByte Group, U. Sydney

        Heine's IntraCONtinental basinS (ICONS) Atlas — 870 global sedimentary basin polygons with per-basin attributes: MAX_FILLKM (maximum sedimentary fill in km), SUB_REGIME (tectonic setting: rift, passive margin, foreland, cratonic sag, ...), AREA_KM2, regional grouping, and 20+ ancillary fields.
