# Notebook IDs

Each notebook has an ID made of its cluster letter (A-K) and its index within that cluster, e.g. `F03`. The file name starts with that ID.

Earlier versions of the suite (including the review-stage manuscript and the Zenodo snapshot of the paper) numbered the notebooks `T01`-`T80` in a single sequence. The table below maps old numbers to the current IDs. Notebook content was revised alongside the relabelling (see `CHANGELOG.md`), so two notebooks can differ in detail, but the old number and the new ID refer to the same notebook.
